# Feed Docs Rewrite Policy

- Status: Active
- Audience: Engineers
- Source of Truth: Yes
- Last Reviewed: 2026-04-12

## 목적

이 문서는 feed 관련 legacy 문서를 삭제하고, 이후 공식 제품 문서를 어떤 기준으로 새로 작성할지 정의한다.

## 원칙

- 기존 FEED PRD 계열 문서는 재사용하지 않는다.
- 새 feed 관련 공식 설계 문서는 현재 코드와 현재 정책을 기준으로 다시 작성한다.
- 과거 문서의 문장과 구조를 그대로 옮기지 않는다.
