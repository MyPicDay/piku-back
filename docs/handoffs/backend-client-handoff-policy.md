# Backend Client Handoff Policy

- Status: Active
- Audience: Backend Engineers, Frontend Engineers, Mobile Engineers
- Source of Truth: Yes
- Last Reviewed: 2026-04-12

## 목적

이 문서는 프론트엔드와 모바일에 전달하는 공식 handoff 문서의 작성 기준을 정의한다.

## 원칙

- handoff 문서는 소비자 관점 변경점부터 작성한다.
- 내부 task 이름과 구현 순서는 넣지 않는다.
- API 계약 변경 시 응답 형식, 필수 필드, 제거된 필드를 우선 기록한다.
