# Documentation Maintenance Runbook

- Status: Active
- Audience: Engineers
- Source of Truth: Yes
- Last Reviewed: 2026-04-12

## 목적

이 문서는 공식 문서 체계 변경 시 어떤 순서로 문서를 추가, 수정, 삭제, 검증할지 정의한다.

## 절차

1. 공식 문서가 필요한지 판단한다.
2. 올바른 카테고리를 선택한다.
3. 메타데이터와 index 연결을 추가한다.
4. `bash scripts/docs-lint.sh`로 검증한다.
